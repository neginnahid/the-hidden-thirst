# The Hidden Thirst

A one page website about the effect of data centers and AI on clean water.
CSC 317 Group Project 1, San Francisco State University.

Live site: (Netlify URL)

## About

Six facts about how data center cooling consumes fresh water, a visual comparison
of direct against indirect water use, and a short section on what AI adds. Every
figure on the page is cited to one of four sources listed at the bottom of the site.

## Built with

HTML and CSS only. No JavaScript, no CSS framework.

- Flexbox for all layout
- CSS custom properties for the color palette
- Pseudo-classes and pseudo-elements for the numbering, the bars and the interaction states
- A media query for screens under 600px
